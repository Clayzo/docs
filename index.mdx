Clayzo is an animation engine built for agents. You describe the motion you want. Your agent writes a typed animation document, looks at the result, and iterates. The `clayzo` CLI previews, reviews, packages and exports that document. Two small players play the same document in the browser.

## What you install

| Package | What it is | Where it runs |
| --- | --- | --- |
| `clayzo` | The CLI: project setup, preview, frame rendering, review, packaging and export | Your machine and CI |
| `@clayzo/animation` | Typed authoring: document types, builders, validation, revision stamping and `.clayzo` packaging | Authoring scripts |
| `@clayzo/webgl-player` | The lightweight player, about 250 KB compressed | Browsers |
| `@clayzo/canvaskit-player` | The full-fidelity player, the same renderer the export uses, about 2.5 MB compressed | Browsers |
| Agent skills | Two skills that teach your agent how to author and how to ship with Clayzo | Claude Code, Cursor, Codex and other agents |

All four packages ship together under one version. Keep them on the same version.

## How a project fits together

<Steps>
  <Step title="Set up once">
    `npx clayzo@latest init` installs the packages and the agent skills in your project.
  </Step>
  <Step title="Author with an agent">
    Your agent writes a TypeScript script that emits an animation document, a JSON file. The types stop it from producing something malformed. The skills stop it from producing something ugly.
  </Step>
  <Step title="Look at it">
    `clayzo render-frame` produces a labelled sheet of frames in a second. `clayzo preview` plays the document in a browser tab. Agents use both to check their own work.
  </Step>
  <Step title="Ship it">
    `clayzo export` renders video or stills. `clayzo package` bundles the document with its fonts and images so a player can play it anywhere.
  </Step>
</Steps>

<Info>
  Authoring, types and validation work offline and without an account. Preview, rendering, review, packaging and export need a sign in. Playback in the browser never contacts Clayzo.
</Info>
